# Warehouse Inventory

Keeps track of the **items** in a *warehouse*, with `quantity` and price.
See the [user guide](docs/guide.md) or <https://example.com/warehouse>.

## Installation

1. Download the [latest release][release]
2. Unpack it, then run `./warehouse --port 8080`
3. Open http://localhost:8080 in a browser.

> The first start creates the database, which takes a moment.
